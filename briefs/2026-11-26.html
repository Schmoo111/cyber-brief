FinCEN: unauthorised access, systems offline

Background: FinCEN (Financial Crimes Enforcement Network) is the US Treasury bureau that collects Bank Secrecy Act (BSA) filings, such as suspicious activity reports (SARs), from banks and analyses them to fight money laundering.

Confirmed (FinCEN notice)
"Unauthorized access to a limited subset of its systems"; some systems taken offline as a precaution. The BSA E-Filing website stays up, but some services may be unavailable.[3]
Filing relief
Order FIN-2026-R002 lets firms using bulk "Secure Direct Transfer Mode" (as of 18 Nov) file reports due 18 Nov–29 Dec by 30 Dec. Filing providers saw batch failures from 18 Nov. Other BSA duties, including monitoring, still apply; the order cites a "service disruption", not the intrusion.[4]
Unknown
When access began, whether data was viewed or taken, and who did it. No claim. Media link it to a run of US government breaches (CIA, FBI, NSA), but no common actor is confirmed.[3]
Why it matters
SARs name customers and suspected criminals; exposure would be serious for banks. Confirm your filing route and backlog; expect phishing posing as FinCEN.

1Password: customer account data taken

Background: 1Password is a Canadian password manager used by millions of people and many firms. GitHub is where software teams store code; CI/CD is the automated system that builds and ships that code.

Confirmed (1Password)
On 19 Nov it began investigating; an attacker used an employee's GitHub account to copy source code, reach CI/CD and push malicious code to back-end services, then download data on a subset of users: names, emails, account IDs, sign-in times, public keys, login-protocol (SRP) values and some tokens from invitation and recovery emails.[2]
Not affected
Vault contents, the keys protecting them, recovery keys, and the apps. Stolen tokens alone cannot open accounts; codes were lengthened.[1]
Actor
Unknown.
Why it matters
No action needed, says 1Password, but expect convincing phishing about "account recovery". Shows how one developer account can reach production.

Palo Alto Networks: firewall takeover flaw patched

Background: Palo Alto Networks is a leading US firewall maker; PAN-OS is its firewall software. Fragnesia, disclosed in May, is a Linux kernel bug that lets a low-level user overwrite system files and become "root", the all-powerful administrator.

Reported
A China-linked group, using AI tools, chained PHP2Shell (a bug giving remote code running, patched by 30 Oct) with Fragnesia to plant hidden web shells on 25 servers, including 24 firewalls. Palo Alto has seen it only against management interfaces exposed to the internet.[5]
Action
Upgrade PAN-OS to the latest fixed release; keep management interfaces off the internet.

92-minute security fix

Run a password check-up on your phone 2 minutes · phone · the passwords saved by Apple or Google

Why now: today's breaches at 1Password and the Hex.pm code store are reminders that login details leak. Your phone can tell you which of your saved passwords have shown up in leaks or are reused, so you fix those first.

  1. iPhone: open the Passwords app (older iPhones: Settings → Passwords) and tap Security (may say "Security Recommendations").
  2. Android or Chrome: open Google Password Manager (in Chrome: ⋮ → Passwords, may say "Passwords and autofill") and tap Checkup.
  3. Start with any password marked compromised or leaked, especially email and banking; tap Change password and use a new, unique one.
  4. If you use a separate password manager (such as 1Password), use its own check, often called Watchtower or "security dashboard".

Done when: no saved password is listed as compromised. If you can't find the option, search your phone's settings for "password". Bonus: if you use 1Password, ignore any email or call asking for your password or Secret Key — the company never asks.

For your work devices and accounts, leave this to your IT team.

Glossary

Bank Secrecy Act (BSA) filing
Reports US banks must send to FinCEN, such as large cash transactions.
Suspicious activity report (SAR)
A confidential report a bank files when it suspects money laundering or fraud.
Password manager
An app that stores all your passwords in an encrypted "vault".
GitHub
An online service where teams store and work on software code.
CI/CD
Automated systems that build, test and release software.
SRP
Secure Remote Password: a login method that never sends your password itself.
Root
The all-powerful administrator account on a computer.
Linux kernel
The core of the Linux operating system, used inside many network devices.
Web shell
A small hidden program on a server that lets an attacker control it remotely.
Management interface
The admin login page used to configure a device.
Command injection
Tricking software into running the attacker's operating-system commands.
Package registry
A public store of reusable code libraries that developers download.
Password hash
A scrambled form of a password; it can sometimes be cracked offline.
Two-factor secret
The hidden value behind the codes your authenticator app shows.
Agentic AI tool
AI that plans and carries out a series of steps itself, such as scanning and exploiting.
Password spraying
Trying a few common passwords against many accounts.
Vishing
Voice phishing: scam calls to trick staff into giving access.
Leak site
A website where extortion gangs post stolen data to pressure victims.
CISA exploited list (KEV)
The US cyber agency's list of flaws confirmed as used in attacks.
Password check-up
A phone or browser tool that flags leaked, weak or reused saved passwords.
