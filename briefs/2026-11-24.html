India: attackers rewired approval steps to send real payments

Background: CERT-In is India's national cyber emergency team; I4C is its government cybercrime coordination centre. Instead of hacking the payment system itself, the attackers changed supplier or partner records and approval links inside business software, so genuine payment runs paid the wrong accounts.

Reported (CERT-In, I4C)
Banks, non-bank lenders, fintechs and firms handling government-linked and partner payouts were hit. I4C describes entry via unpatched or badly configured internet-facing servers, then money sent to "mule" accounts at several banks and moved out fast. Losses are described only as "multi-crore" (tens of millions of rupees).[1]
Actor
CERT-In attributes these payment cases to no one. Separately it warns a group it calls Crafty Falcon is using AI attack tools against financial firms; no link to the payments is stated.[1]
Unknown
Victim names and total losses. The advisories themselves were not retrieved (single source).
Why it matters
Payments that pass normal approvals raise no alarm. Independent checks on changes to beneficiary records are the defence.
HighConfidence: HighCloud flaw exploited

Azure API Management: secrets stolen through a Microsoft flaw

Background: Azure API Management (APIM) is Microsoft's cloud gateway that sits in front of a firm's APIs, the connections apps use to talk to each other, and stores the keys and passwords those connections need. Equinor is Norway's state-controlled energy company.

Confirmed (Microsoft)
Found 18 Nov, access path closed 19 Nov. Older "Classic" Developer, Basic, Standard and Premium tiers were exposed where not set up to Microsoft's guidance; v2 tiers and Consumption were not. Stored secrets, sign-in client secrets, subscription keys and management tokens may have been taken. The fix does not cancel stolen credentials.[3]
Confirmed (Norway's NSM)
Several Norwegian organisations and others abroad were affected, including Equinor and Skagerak Energi, which both report no evidence of data loss. Attacker unknown.[2]
Action
Treat all APIM Classic secrets as compromised: replace them, check systems they unlock, review logs.
CriticalConfidence: MediumExploited flaw

ScreenConnect: a "customer" in a support session can take over the technician's PC

Background: ConnectWise ScreenConnect is remote-support software used by IT teams and managed service providers (MSPs, outside firms that run IT for others). The flaw (severity 9.9 of 10) lets the person on the other end of a session push a file to the technician's computer and run it, with no prompt.

Researchers found (Huntress)
Attacks from 20 Oct to 16 Nov, including against an MSP; one rogue install took about nine seconds. Huntress also logged at least 688,000 blind attempts across 42 servers.[4]
Action
Upgrade technician clients to 26.6.5 or newer, or remove the file-transfer permission until you can; check technician PCs and change passwords they held.
Why it matters
Support staff have wide access; one hijacked laptop can reach many systems, at a bank or its suppliers.
HighConfidence: MediumExploited flaw, no patch

Old ASP.NET add-on lets anyone take over a web server

Background: Idunno.AntiCsrf is a free add-on, last updated in 2008, that protected older Microsoft ASP.NET "WebForms" websites against forged form submissions. It unpacks incoming data without checking it is genuine ("insecure deserialisation"), so one crafted request runs the attacker's code.

Confirmed (Google, Mandiant)
Found by Google Cloud and Mandiant responders; exploitation seen in the wild, attacker not named. Severity 9.3. There will be no fix.[5]
Action
Search code for the library and replace it with Microsoft's built-in anti-forgery protection.
Why it matters
Banks still run long-lived internal and customer web apps built this way.
LowConfidence: HighSupplier change

CrowdStrike to buy Zscaler for about $43.9 billion

Background: CrowdStrike makes security software for computers and servers; Zscaler runs cloud services that control staff access to apps and the internet. Many banks use one or both.

Confirmed (companies)
An all-share deal approved by both boards, expected to close in the second half of CrowdStrike's 2028 financial year; products to be merged onto one platform.[11]
Why it matters
Concentration risk: more of a bank's defences would depend on one supplier. Worth noting in third-party risk reviews.
LowConfidence: MediumEspionage tooling

Webworm: free VPN software rebuilt to hide spies' access

Background: SoftEther is free, legitimate VPN software. Rapid7, a security firm, found a copy rebuilt to look like network-monitoring software, with its traffic patterns changed to dodge detection, giving a hidden tunnel into victim networks.

Researchers found
Rapid7 links it to Webworm, a China-aligned spy group, with moderate confidence. Known targets are government, IT and power firms in Russia, Georgia, Mongolia and Asia; no banks named.[12]

N-able Mail Assure: flaw named, now on CISA's exploited list

Background: N-able sells IT management tools to MSPs; Mail Assure is its cloud email-filtering service. The flaw is a "server-side request forgery": a logged-in API user could make the server connect to internal machines it should not reach.

What's new
N-able disclosed the flaw it found while investigating the break-in to one server and fixed it; dashboard and APIs are back. Old API tokens were cancelled, so integrations need new ones. It reports no evidence customer mail was taken; root-cause report due within two weeks. CISA added the flaw to its exploited list on 23 Nov.[7][6]
MediumConfidence: HighUpdate

MONAI Label: added to CISA's exploited list

Background: MONAI Label is open-source software for labelling medical images. Amazon reported attackers' AI agents found and used its file-upload flaw, a "path traversal" that writes files outside the intended folder.

What's new
CISA listed it as exploited on 23 Nov.[6]
MediumConfidence: MediumUpdate

AI hosting firms: bait test shows prompts were copied unnoticed

Background: Inference providers run AI models for other companies. Anything sent to them, including passwords pasted into prompts, passes through their servers.

What's new
Dragos, an industrial-security firm, sent about two million prompts laced with traceable fake keys. At least three providers were breached without noticing; about 200 fake cloud keys were stolen in late October and tested by attackers. Providers were not named by Dragos.[9]
Action
Keep secrets out of AI prompts; know which providers your AI tools route through.
LowConfidence: LowUpdate

FBI crime database: President says he was briefed

Background: NCIC is the FBI's national database of wanted people, warrants and stolen property used by police.

What's new
Anonymous sources told CNN and AP the attack happened on Thursday. President Trump said he had been briefed. The FBI has not commented; what data was reached is unknown.[8]
LowConfidence: MediumUpdate

BADBOX 3.0: disrupted

What's new
HUMAN, an anti-fraud firm, says it disrupted the fraud network, and Google separately took down a related botnet that controlled some of its servers.[10]

Glossary

API
A connection that lets one piece of software ask another for data or actions.
API gateway (Azure API Management)
A service that sits in front of a firm's APIs, controls who can use them and stores the keys they need.
Secret / credential
A password, key or token that proves a person or program is allowed in.
Token
A digital pass that lets software act as a user without retyping a password.
Mule account
A bank account used to receive and quickly move stolen money.
MSP
Managed service provider: an outside firm that runs IT for other organisations.
Remote-support tool
Software that lets a technician see and control someone else's computer.
ASP.NET WebForms
An older Microsoft technology for building websites, still common in long-lived business apps.
CSRF
Cross-site request forgery: tricking a logged-in user's browser into submitting a form they didn't intend.
Insecure deserialisation
When software unpacks incoming data without checking it, letting crafted data run code.
Server-side request forgery (SSRF)
Making a server connect to internal machines on an attacker's behalf.
Path traversal
A trick that makes software read or write files outside the folder it should use.
Code injection
Slipping attacker instructions into text that a program later runs as code.
npm
The main public store of free JavaScript code libraries.
VPN
Virtual private network: an encrypted tunnel between computers or networks.
Inference provider
A company that runs AI models for others and processes their prompts.
Botnet
A network of infected devices controlled together by criminals.
CISA exploited list (KEV)
The US cyber agency's list of flaws confirmed as used in attacks.
Concentration risk
Depending heavily on a single supplier, so one failure has a large impact.
