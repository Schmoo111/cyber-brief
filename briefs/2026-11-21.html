Rakuten Securities: real customer data left in a test system

Background: Rakuten Securities is one of Japan's largest online stockbrokers, part of the Rakuten e-commerce and banking group. A test environment is a copy of a system used to try out changes; it normally holds fake data.

Confirmed
Disclosed 17 Nov; data may have leaked on 11 Nov. Real data had been copied into the test system for an upgrade. Up to 11.25 million accounts had login IDs exposed; up to 4.47 million more also had names, employers, withdrawal bank accounts, income and assets. Rakuten says passwords and PINs were not leaked and it has seen no unauthorised trading.[5]
Status
Figures are upper limits; entry route and attacker unknown.
Why it matters
Live data in less-protected test systems is a common shortcut at banks too.

Credit unions: app supplier missed a breach for six weeks

Background: Wellington IT is a Belfast software firm that runs mobile banking apps for credit unions, member-owned savings and loan co-operatives, mainly in Ireland.

Confirmed
Attacked early October; its first investigation missed the data breach, and credit unions were told only on 16 Nov. Ireland's data regulator has over 40 breach reports; UK credit unions are also reporting. Only saved payee details were affected; no sign of stolen funds.[6]
Why it matters
One small supplier serving many lenders is a single point of failure.

SAP NetWeaver portal: year-old flaw now used in attacks

Background: SAP's NetWeaver Enterprise Portal is the web front door to SAP business systems, used by many banks for finance and HR. The flaw lets an attacker with no login steer a lookup (JNDI) to their own server, exposing or changing server information.

What happened
CISA added it to its exploited list on 20 Nov, deadline 23 Nov. SAP fixed it in November 2025 (SAP Note 3660969). It is rated medium (6.5).[3][15]
Status
No public details of attackers. Confirm the fix is installed.

Ruby2Shell: a text bug in a popular web language

Background: Ruby is a programming language behind many websites (often via the Rails framework) and tools such as GitLab. Converting "ß" to capitals gives "SS": Ruby makes room for one letter but writes two, a buffer overflow, like stuffing more cash into an envelope than it can hold.

What happened
Fixed with six other flaws. Web apps could be hit without a login, but a takeover is hard; crashes are likelier. No attacks or public exploit yet.[10]
Action
Upgrade Ruby (4.0.10, 3.4.13, 3.3.14 or newer) and patch GitHub Enterprise Server and GitLab.
MediumConfidence: HighNew flaw

Linux KVM: a virtual machine could read its host's memory

Background: KVM is the part of Linux that runs virtual machines, used by many clouds and private data centres.

What happened
A Terra Security researcher read a host's memory from inside a guest machine. Only AMD hosts with "nested" virtualisation (on by default) are affected, and the attacker must already control a guest. No attacks seen; some Linux distributions lack a fix.[11]
Action
Patch host kernels when available, or turn off nested virtualisation.

SonicWall: older firewalls get no more fixes

What happened

92-minute security fix

Turn on instant alerts for every payment from your bank account 2 minutes · phone · your personal bank and card apps

Why now: this week's fraud arrests involved callers posing as bank staff who took over accounts and sent money out, and leaked customer emails from the JPMorgan, Visa and Mastercard suppliers make such calls more convincing. An instant alert lets you spot a payment you did not make within seconds.

  1. Open your bank's own app (not a link from a text or email) and tap Settings, Profile or More.
  2. Find Notifications or Alerts. Switch on push alerts for all card payments, money leaving your account, new payees and sign-ins from a new device.
  3. Allow notifications for the app on your phone: on iPhone, Settings → Notifications → your bank app → Allow Notifications; on Android, Settings → Notifications → App notifications and turn the bank app on.

Done when: a small test purchase pings your phone. Bonus: do the same for each credit card app, and help a parent set it up.

For your work devices and accounts, leave this to your IT team.

Glossary

Push alert
A message an app pops up on your phone's screen straight away.
Third-party (supplier) risk
The danger that a company you share data or access with is breached instead of you.
Data extortion
Stealing data and threatening to publish it unless paid.
Test environment
A copy of a system used to try changes; it should hold fake data.
Credit monitoring
A service that warns you if someone applies for credit in your name.
CISA exploited list (KEV)
The US cyber agency's list of flaws confirmed as used in real attacks, with fix deadlines for US agencies.
JNDI
A Java feature that looks up resources by name; if an attacker controls the lookup, the server can be tricked into talking to them.
Deserialisation flaw
A bug where a program unpacks data from outside without checking it, letting attackers slip in commands.
Buffer overflow
Writing more data into a memory space than it can hold, which can crash a program or let an attacker run code.
Remote code execution
Running your own commands on someone else's computer over the network.
Virtual machine / nested virtualisation
A software copy of a computer; nested means running virtual machines inside a virtual machine.
Kernel
The core of an operating system, which controls memory and hardware.
End of life
A product the maker no longer fixes.
HTTP/2
A faster version of the protocol browsers and servers use to talk.
DNS
The internet's address book, turning names into network addresses.
Accessibility services
Phone features that let apps read and control the screen for disabled users; malware abuses them.
Account takeover
A criminal gaining control of someone's online account, often by tricking them into handing over login details.
DDoS
Flooding a website with traffic so real users can't reach it.
