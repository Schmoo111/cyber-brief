BankWeaver: digital-banking middleware abused

Background: Temenos is a Swiss banking-software maker serving banks in over 150 countries. Its Quantum Fabric is middleware: it sits between customers' banking apps and a bank's identity systems, databases and payment services. Forescout is a US security firm.

Reported (Forescout, 19 Nov; widely picked up 26 Nov)
At one financial institution in early September, an internet-facing login service accepted "anonymous" access. Attackers swapped an anonymous token for an administrator token without a password, uploaded a malicious service and ran commands. They installed FabricShell, a web shell that also runs database queries, and FabricShadow, a spy tool.[3][4]
Scope
One confirmed victim (region not given). Six more banks in Asia, the Middle East, Europe and the Americas have the same exposure; no compromise confirmed there. Attack traffic came through hacked UK home routers and storage boxes.[3]
Vendor
Temenos says it was a configuration issue (service set to anonymous, not private); it issued updates and guidance. No CVE.[3]
Actor
Unknown.
Why it matters
Direct path to customer data and payment back-ends. Ask whether you run Quantum Fabric or Infinity Spotlight; make its admin and login services private, apply Temenos updates and rotate credentials.
HighConfidence: HighExploited flaws

Mitel MiCollab: zero-days used for data theft

Background: Mitel is a Canadian business-phone company; MiCollab is its calling, messaging and conferencing server. A zero-day is a flaw attacked before a fix exists.

Reported (Accenture)
Accenture's Apex Labs saw attackers plant a web shell, gain full control within about 30 minutes, steal passwords, move into identity systems and reach backup and database servers within 20 hours. Two organisations hit; possibly extortion; no known group linked.[6]
AI angle
Attacker servers talked to two commercial AI services during the attack. Suspected, not confirmed.[6]
Action
Upgrade MiCollab (patched 16 Nov) and check for signs of earlier compromise.
HighConfidence: MediumSoftware supply chain

PolinRider: thousands of code projects booby-trapped

Background: GitHub is where developers store code. PolinRider steals developers' GitHub keys, then quietly rewrites their projects to add a hidden loader that fetches malware, using a cryptocurrency wallet as a hard-to-block noticeboard for its instructions.

Reported
Apiiro, a security firm, counts at least 7,609 repositories from 2,330 accounts; 2,040 were hit between 27 Oct and 6 Nov. Earlier waves stole passwords, cookies and crypto wallets.[5]
Attribution
Assessed, not confirmed, as North Korean, alongside its "Contagious Interview" fake-job campaign.[5]
Why it matters
Bank developers who pull open-source code or do "take-home tests" are targets. Pin trusted versions; protect GitHub tokens.

Drupal: patch left a gap, now exploited

Background: Drupal is free, widely used website software. Last week's flaw let anyone use the built-in installer page to take over a site.

What's new
New flaw CVE-2026-136716: sites in "unusual or incomplete install states" stayed vulnerable after the 18 Nov fix, and this is invisible in the admin screens. Drupal confirms exploitation.[2]
Action

92-minute security fix

Remove browser extensions you don't use 2 minutes · laptop (and iPhone) · Chrome, Edge, Safari or Firefox

Why now: researchers found over 250 browser add-ons that behave normally but secretly collect browsing data and tamper with shopping links when installed from a paid search ad. Today's fake job tests also steal what's stored in Chrome. Fewer add-ons means fewer ways in.

Where it lives depends on your browser:

Chrome
  1. Click ⋮ (top right) → Extensions → Manage Extensions.
  2. Click Remove on anything you don't recognise or haven't used in months.
Microsoft Edge
  1. Click ··· → Extensions → Manage extensions.
  2. Click Remove on anything unfamiliar.
Safari (Mac)
  1. Open Safari → Settings (may say "Preferences") → Extensions.
  2. Select one and click Uninstall.
Firefox
  1. Click ☰ → Add-ons and themes → Extensions.
  2. Click ··· next to one → Remove.
iPhone (Safari)
  1. Open Settings, find Safari (newer iPhones: under Apps) → Extensions.
  2. Turn off or delete the app behind any you don't need.

Done when: only add-ons you know and use are left, ideally from well-known makers. If you can't find the menu, type chrome://extensions or edge://extensions in the address bar. Bonus: do the same on a parent's laptop.

For your work devices and accounts, leave this to your IT team.

Glossary

Middleware
Software that connects customer-facing apps to a company's back-end systems.
Token
A digital pass a system issues after login, used instead of re-entering a password.
Web shell
A small hidden program on a server that lets an attacker control it remotely.
Zero-day
A flaw attackers use before the maker has released a fix.
Root
The all-powerful administrator account on a computer.
Identity infrastructure
The systems that manage staff logins and permissions, such as Active Directory.
Repository
A project folder of code stored on a service such as GitHub.
Commit
A saved change to code in a repository.
Loader
A small piece of malware whose job is to download and start the main malware.
Package (NuGet, npm)
A reusable code library downloaded from a public store.
Command injection
Tricking software into running the attacker's operating-system commands.
HTTP/2
A newer, faster version of the protocol web browsers use to talk to websites.
Ransomware
Malware that locks files and demands payment to unlock them.
CVE
The standard ID number given to a publicly known security flaw.
Browser extension
An add-on that gives a web browser extra features; it can often see the pages you visit.
