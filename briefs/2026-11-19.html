CriticalConfidence: MediumNew vulnerability

nginx2root: a ten-year-old flaw in NGINX web servers

Background: NGINX is free web server software (owned by F5) that sits in front of a large share of the world's websites and apps, often as the first thing internet traffic touches. HTTP/2 is a modern, faster version of the web's basic communication protocol.

What happened
A memory flaw in how NGINX handles HTTP/2 traffic, present since 2015, was disclosed and fixed on 18 Nov. In some setups an attacker can run code on the server without logging in. Getting full control of the machine needs a second, separate Linux flaw.[4]
Limits
It needs HTTP/2 switched on and a standard memory protection (ASLR) defeated. Security firms Wiz and Xint report working attacks in tests; one method needs about 128 GB of traffic. Test exploit code is public.[4]
Status
No attacks reported; not on CISA's exploited list. Single media source (Unverified on detail).
Action
Upgrade NGINX to 1.31.9 or 1.30.7 or newer; NGINX Plus to the fixed builds.
Why it matters
Banks run NGINX widely, often directly on the internet. Public test code shortens the time to real attacks.
HighConfidence: MediumNew vulnerability

F5 BIG-IP: six critical flaws, hotfixes only

Background: F5 is a US company whose BIG-IP devices balance and secure traffic to banks' websites and apps, and often run remote-access logins (APM).

What happened
On 18 Nov F5 disclosed six critical "buffer overflow" flaws in BIG-IP's traffic engine. Without logging in, an attacker can crash it, cutting off traffic, and possibly run code. Four were found by researchers at watchTowr. Each only applies when certain optional features or traffic rules (iRules) are in use.[5]
Status
No exploitation reported. No workaround; fixes are "engineering hotfixes" that F5 says lack full testing.
Action
Check whether your configurations match F5's list; apply hotfixes on matching devices, then move to full releases when out.
HighConfidence: MediumSoftware supply chain

Microsoft Agent Framework: poisoned releases steal cloud keys

Background: Agent Framework is Microsoft's free toolkit for building AI agents in the Python programming language, downloaded about 190,000 times a month from PyPI, the main public store for Python code.

What happened
On 17 Nov someone published two fake versions (1.26.1 and 1.26.2). They worked normally but secretly harvested passwords, keys and access tokens for Azure (Microsoft's cloud), Azure DevOps and GitHub. PyPI has removed them. How the attacker got publishing rights is unknown.[6]
Actor
Unknown.
Action
Search developer machines, build pipelines and containers for those versions; if found, rebuild and change all exposed credentials.
MediumConfidence: MediumEspionage

Russian spies used one victim's data to breach another

What happened
Google's Mandiant reported on 18 Nov that Cold Relic took over an administrator account at one US organisation, copied its files and staff directories, then posed as its employees to phish a second US organisation. It kept reading email for months, even after password resets.[8]
Why it matters
Trusted-partner impersonation is hard to spot. Treat unusual requests from known suppliers with care and check how admin accounts are protected.

CriticalConfidence: HighUpdate

Java4Shell: CISA says patch immediately

Background: Java runs much of banks' business software. Java4Shell is a flaw in how Java decodes Base64 data that can let an attacker take over some Java services without a password, on servers with recent Intel and AMD chips.

What's new
CISA urged immediate patching, starting with internet-facing systems, and warned that Java hidden inside other products may not show up in inventories.[1] Oracle fixed it in its November update, rating it 8.1 out of 10; that update fixed about 655 issues across Oracle products.[3] Calif says it found the bug with AI in about an hour.[2]
Status
No attacks reported. Calif is withholding full attack code.
HighConfidence: MediumUpdate

n0n's deadline passes with no Visa or JPMorgan leak seen

Background: n0n, a criminal extortion group, said on 16 Nov it had data from Visa, Mastercard and JPMorgan Chase and gave them 48 hours to pay. Visa blamed an Asia-Pacific supplier and said card data was not affected.

What's new
As of the morning of 18 Nov, no leak of Visa or JPMorgan data had been reported. n0n did publish about 500 MB said to be from Expedia (travel bookings) on 17 Nov, showing it sometimes follows through. Mastercard has still not commented.[9]
Claimed vs confirmed
Listed data is described as marketing and cardholder records, not card numbers. None of it is confirmed.

Optimizely website attack: no new disclosures by affected banks found today.

Glossary

Web server
Software that receives requests from browsers and apps and sends back web pages or data.
HTTP/2
A newer, faster version of the protocol browsers and servers use to talk to each other.
ASLR
A protection that shuffles where programs sit in memory so attackers can't easily aim at them.
Buffer overflow
A bug where a program writes more data than a memory area can hold, which can crash it or let an attacker run code.
Hotfix
An urgent, narrowly tested fix released before a full software update.
iRule
A custom traffic-handling rule written by administrators on F5 devices.
PyPI
The Python Package Index, the main public store where developers download Python code libraries.
Access token
A digital pass that proves a user or program is already logged in, so it can act without a password.
Phishing
Fake messages designed to trick people into giving up passwords or clicking malicious links.
Remote code execution
When an attacker can make someone else's computer run commands over a network.
CISA exploited list (KEV)
The US cyber agency's list of flaws confirmed as used in real attacks.
Extortion group
Criminals who steal data and demand payment not to publish it.
